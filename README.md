# 飞书客户使用健康度看板（示例）

基于飞书上线客户使用数据搭建的客户健康度看板 Demo，纯前端 HTML + ECharts，可直接通过 GitHub Pages 访问。

## 看板内容

- **总览**：客户 KPI、健康档位分布（绿/黄/红）、风险客户 Top、DAU/WAU 活跃趋势、AI 消耗趋势
- **客户明细**：15+ 维指标全量表格，支持排序与行业/城市/档位筛选，点击行可下钻详情
- **AI 消耗榜**：AI Token 消耗排名、AI 渗透率排名、AI 功能消耗占比、AI 环比
- **预警清单**：健康分风险 / 活跃度下滑 / AI 消耗骤降 / 长期沉默 / Base 渗透偏低

## 健康度模型（示例口径）

```
健康分 = 激活率 × 40% + Base 渗透率 × 30% + 主版本使用时长 × 30%（人均周使用小时，6h/周满分）
档位：≥80 健康（绿）｜60-79 关注（黄）｜<60 风险（红）
```

## 数据说明

页面内数据为**虚构示例数据**（2026.03 – 2026.10），仅用于演示结构与交互，非真实客户数据。

## 接入真实数据

替换 `index.html` 中 `DATA` 数组的字段（客户名、DAU、WAU、激活率、Base 渗透率、主版本时长、AI Token 消耗等），页面结构与交互无需改动；如需从 Aeolus / Tea 自动取数，可另行接入数据源。
